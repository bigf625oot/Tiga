旨在通过“左侧对话/结果区”与“右侧执行/过程区”的联动，为用户提供透明、可控且专业的智能体协作体验。
智能体对话执行详情页面需求文档 (PRD)
1. 整体布局设计
分栏结构：采用左右分栏布局。
左侧 (Conversation & Result Panel)：侧重于“人机对话”与“最终产出”。宽度约 40%-50%。
右侧 (Execution & Task Panel)：侧重于“任务拆解”与“执行细节”。宽度约 50%-60%。
自适应性：支持中间分割线左右拖拽，右侧面板可折叠。
2. 左侧：对话与摘要面板 (Dialogue & Synthesis)
左侧是用户感知智能体“灵魂”的地方，采用流式输出。
2.1 思考过程 (Thought Chain)
表现形式：使用浅灰色背景或带图标的折叠框，标题为“思考中...”或“Thinking”。
内容：展示 Agent 的内心独白。例如：“用户需要分析这三份报表，我需要先提取数据，然后进行同比分析，最后生成摘要。”
状态：
进行中：文字流式打字机效果，带有 Loading 动画。
已完成：默认收起，仅显示“已思考 5 秒”，点击可展开查看完整逻辑。
2.2 执行日志摘要 (Mini Execution Logs)
表现形式：简洁的单行状态更新。
内容：
[搜索] 正在检索关于“2024 AI 行业趋势”的信息...
[分析] 正在处理 3 个 PDF 文件...
[绘图] 正在生成趋势图表...
交互：点击特定的日志条目，右侧面板自动定位到对应的详细步骤。
2.3 工具调用卡片 (Tool Invocation)
表现形式：紧凑的小卡片，显示工具图标和名称。
示例：[Icon] Google Search、[Icon] Python Interpreter、[Icon] File System。
2.4 最终产出物 (Artifacts)
表现形式：大面积的渲染卡片。
类型：
文档卡片：显示标题、格式（PDF/Markdown/Docx）、文件大小。点击卡片右侧弹出“预览全屏”或直接打开右侧的预览模式。
代码卡片：显示语言类型及核心摘要。
多媒体：图片缩略图、表格预览。
交互：提供“下载”、“复制内容”、“添加到上下文”按钮。
3. 右侧：任务执行详情面板 (Execution & Sandbox)
右侧是智能体的“身体”和“实验室”，展示具体的重活累活。
3.1 任务概览 (Task Header)
任务标题：当前总目标（如：撰写行业调研报告）。
进度条：展示 已完成步骤 / 总步骤。
状态标签：Running（运行中）、Success（已完成）、Failed（失败/待干预）。
3.2 任务步骤列表 (Task Steps Timeline)
垂直时间线：每个步骤为一个节点。
步骤属性：
序号与名称：Step 1: 环境准备；Step 2: 数据抓取。
执行状态：绿勾（成功）、红叉（失败）、转圈（进行中）。
耗时统计：显示该步骤运行的时间。
3.3 沙箱执行详情 (Sandbox Detail)
点击时间线中的某个步骤，下方或侧边展开具体的执行细节：
执行指令 (Command/Script)：
如果是 Python：展示具体的 Code Block（支持语法高亮）。
如果是浏览器操作：展示具体的操作序列（如 Click #submit_btn, Type "AI trends"）。
运行环境输出 (Standard Output/Logs)：
终端风格：黑底白字或深色背景。
实时滚动：展示代码运行后的打印信息、网络请求状态码、安装插件的进度等。
错误堆栈：如果报错，高亮显示错误行及 Traceback。
3.4 资源监控 (Optional)
如果是重计算任务，可微缩显示 CPU/内存占用、API Token 消耗统计。
4. 交互联动逻辑 (Interaction Logic)
自动随动：当左侧输出到某个阶段时，右侧自动滚动到对应的 Task Step，并展开沙箱日志。
点击溯源：用户点击左侧摘要中的“分析数据”，右侧立即切换到执行该逻辑的具体 Python 代码块。
结果预览 (The "Preview" Mode)：
当 Agent 生成了一个 HTML 页面或 React 组件，右侧面板上方会出现切换 Tab：Code | Preview。
点击 Preview 可直接在右侧沙箱内渲染出网页效果。
人工干预：
在右侧执行步骤中，如果遇到权限申请（如：是否允许删除文件），会出现“Approve / Deny”交互按钮。
5. UI/UX 细节建议 (Visual Specs)
配色方案：
左侧对话：温暖、干净，使用标准的 IM 对话气泡。
右侧执行：冷色调、极客感，使用 Fira Code 等等宽字体。
动效：
Task 切换时使用平滑的位移动画。
代码执行时，左侧对应的工具图标增加呼吸灯效果。
空状态：
右侧初始显示“等待任务分配...”，带有极简的 Agent 待机动画。
6. 需求场景举例 (Example Scenario)
用户输入：“帮我爬取热搜前十，存成 Excel 并写一段分析摘要。”
左侧展示：
[Thought] 我需要先使用 Browser 工具访问热搜榜。
[Log] 正在读取网页数据...
[Log] 正在调用 Python 转换 Excel...
[Artifact] 热搜分析.xlsx (点击预览)
[Response] 这是为您准备的分析摘要...
右侧展示：
Step 1: 爬取数据 (Status: Done) -> [Detail] 展示具体 Playwright 爬虫代码和日志。
Step 2: 数据清洗 (Status: Done) -> [Detail] 展示 Pandas 处理过程。
Step 3: 文件生成 (Status: Done) -> [Detail] df.to_excel('result.xlsx') 执行成功输出。
