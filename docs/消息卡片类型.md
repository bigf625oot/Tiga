### 1. 核心 Block 的 Markdown 映射物理逻辑
根据 index.ts:L166-L184 定义的 18 种 ContentBlock ，转换规则必须具备绝对的确定性：

- TextBlock L43 ：大模型的最终回复。直接原样输出为 Markdown 文本。
- ThoughtBlock L26 ：Agent 的思维链 (CoT)。必须降级为 HTML 的 <details><summary>🧠 思考过程</summary>...<details> ，避免污染正文视觉。
- PlanBlock L38 ：任务规划。需要映射为 Markdown 的 Task List（ - [x] 代表 completed ， - [ ] 代表 pending / running ）。
- ActionBlock L71 ：文件修改动作。核心是提取 diff 字段，并包裹为 ```diff 代码块，同时附带 path 文件路径说明。
- TerminalBlock L64 ：终端命令执行。需合并 command 和 output ，转化为 ```bash 和 ```text 的组合代码块。
- ToolCallBlock L48 & ToolResultBlock ：工具调用。可序列化为带有工具名 ( tool_name ) 的 ```json 参数块和结果块。
- SearchBlock L89 & KbRetrievalBlock ：检索上下文。应映射为 Markdown 的引用语法 > [1] [Source Title](URL) 或脚注。
- VisualizationBlock L103 ：图表渲染。如果是 mermaid ，直接转为 ```mermaid 代码块；如果是 echarts / recharts ，则转为描述性文本或附带的数据 JSON 块。
- ImageBlock L109 ：图片资源。映射为标准的 ![alt](url) 语法。
