# Tiga 系统智能大脑 (Intelligence Hub) 功能架构与核心特性全景解析

**定位**: 本模块非传统 CRUD 后端，而是 Tiga 系统的核心认知大脑。通过抽象剥离业务表象，直击“数据炼金术”的物理逻辑，实现基于混合模态（Graph+Vector）的超大规模知识图谱与增强生成（GraphRAG）架构，构建出具备高壁垒的技术护城河。

---

## 1. 异构数据吞吐与认知感知引擎 (Knowledge Extractor)
本子系统充当系统的“感知神经”，负责高并发、多模态的解析，并运用策略模式保证极端脏数据下的高可用性。

*   **多态动态解析编排 (Orchestrator)**
    *   **策略降级解析**: 针对 PDF 等复杂格式，内置 Docling, PyMuPDF, pdfplumber, OCR 等多种解析后端，采用首件成功（First-Success）容错机制。
    *   **多模态支持**: 原生支持 PDF, DOCX, TXT 等多格式字节流或本地文件读取。
*   **语义切片与分块 (Text Splitter)**
    *   **上下文感知切分**: 保证 Token 切片过程中的语义连续性，为后续的向量化与实体抽取提供高质量语料。
*   **高密度知识升维萃取 (Entity & Relation Extractor)**
    *   **实体与关系萃取**: 将扁平的非结构化文本升维成高密度的实体节点（Node）和拓扑关系（Edge）。
    *   **隐式层级关系推断**: 针对孤立实体（如“分支机构”），强制启动 LLM 自动补全至“集团总部”的隶属关系，增强图谱拓扑的连通性。
    *   **溯源绑定**: 强制将源文档本身提取为独立实体，所有提取出的节点均与源文档建立关联。

## 2. 双轨制混合模态存储架构 (Storage & Indexing)
系统“海马体”，解决高维语义模糊与拓扑确定的矛盾。

*   **高维向量场 (Vector Store)**
    *   **双引擎支持**: 兼容 Chroma 与 PGVector，实现细粒度文本 Chunk 的语义映射（Embedding），依赖高精度 SIMD 计算保证相似度召回的极致性能。
*   **图数据库拓扑网 (Graph DB)**
    *   **Neo4j 驱动**: 通过节点与边引擎（`models/node.py`, `models/edge.py`）将孤立的知识点联结成网。
    *   **图谱自动纠错**: 包含 `relation_fix.py`，实现图谱构建过程中的脏边清理与关系重对齐。

## 3. 增强生成与认知检索中枢 (LightRAG / GraphRAG)
系统“前额叶”，摒弃传统 RAG 极易产生幻觉的缺陷，通过引入图论约束生成质量。

*   **图文混合检索算法 (Graph+Vector Retrieval)**
    *   **锚点与一跳邻居提取**: 运用 Pagerank 和图论算法寻找问题 Anchor 实体，再提取一跳（1-hop）邻居子图，实现对跨文档长逻辑链的精准召回。
*   **动态上下文隔离与防污染机制**
    *   **精确域控制**: 在进行“当前文档问答”时，采用 `doc#id` Marker 强制切断全局库噪音污染，实现内存逃逸控制在认知层面的完美映射。
*   **严格的提示词工程 (Prompt Engineering)**
    *   **强制 In-text Citations**: 生成结果必须包含严格的 `[n]` 溯源引用标号，每一条事实都必须可被反向追踪。
*   **图数据智能分析网关 (NL2Chart)**
    *   **NL2Cypher & NL2Graph**: 将用户的自然语言（NL）降维映射为图查询（Cypher）或直接输出复杂图谱子网。
    *   **动态图谱可视化**: 后端直接将检索到的知识图谱转化为前端 ECharts 可直接渲染的 Force-Directed Graph 或其他图表格式。

## 4. 意图路由与开放域融合 (NLU & Search)
系统的外部感官边界，通过状态机映射决定知识获取策略。

*   **轻量级意图分类器 (NLU Classifier)**
    *   **零冗余路由**: 摒弃 `if-else`，通过 NLU 智能判定用户的查询需要走本地图谱、单文档精读还是开放网络检索。
*   **开放域检索网关 (Search Service)**
    *   **实时知识对齐**: 集成全网新闻与泛搜接口，弥补本地静态图谱在时间维度上的滞后性，实现 Zero-shot 增强。

## 5. 高度解耦微服务暴露 (MCP Server)
*   **Model Context Protocol (MCP)**
    *   **认知原语输出**: 封装底层所有脏活累活（分块、向量化、检索），通过 MCP 协议向上层 Agent 提供标准化的工具调用接口，具备未来十年的演进范式。

---

## 架构确定性与性能权衡 (Determinism & Trade-offs)
1. **网络连接句柄复用**: LightRAG 引擎全面采用带有严格 Timeout 和 Max Retries 的共享 `AsyncOpenAI` 连接池，彻底杜绝高并发吞吐下的 Socket 耗尽问题。
2. **零拷贝与缓存感知**: Chunk 缓存、GraphML 缓存加载采用基于 `mtime` 的懒加载机制（Lazy Load），最大化降低磁盘 I/O 带来的 CPU 惩罚。
3. **确定性约束**: 传统 RAG 是概率修补，而此处的 GraphRAG 用图拓扑的“物理连通性”将 LLM 禁锢在确定性的轨道上，在极端边界条件下依旧具备 100% 的可预测性。
