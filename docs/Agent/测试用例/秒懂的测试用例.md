## 自动化全链路执行

本目录已提供一套可直接跑的自动化测试套件与脚本：

- 套件文件：[秒懂-全链路测试套件.json](file:///d:/Tiga/docs/Agent/测试用例/秒懂-全链路测试套件.json)
- 运行脚本：[miaodong-e2e.mjs](file:///d:/Tiga/frontend/scripts/miaodong-e2e.mjs)
- 判分规则：[秒懂-全链路判分规则.md](file:///d:/Tiga/docs/Agent/测试用例/秒懂-全链路判分规则.md)

前置条件：

- 前端服务已启动并监听 `http://localhost:5173`
- `http://localhost:5173/api/v1/health/` 返回 `200`

执行（推荐在仓库根目录）：

```powershell
cd d:\Tiga
node .\frontend\scripts\miaodong-e2e.mjs
```

常用参数：

- `--baseUrl http://localhost:5173`：自定义服务地址
- `--filter <regex>`：仅跑匹配用例 id（如 `--filter work_`）
- `--outDir <path>`：输出目录（默认 `docs/Agent/测试用例`）
- `--sessionId <id>`：复用已有会话（默认创建临时会话）
- `--keepSessions`：不自动删除临时会话（便于复盘）

输出：

- `秒懂-全链路测试报告-<时间戳>.md`
- `秒懂-全链路测试结果-<时间戳>.json`
- `秒懂-用例输出-<用例id>-<时间戳>.json`

用例：
一、 职场与生产力场景 (高效办公)
周报生成： “把这周干的杂活整理成一份正经的周报。”（测试模型对非规范语料的结构化能力）
竞品调研： “我想了解最近很火的 AI 绘画工具，帮我拉个对比表。”（测试自主搜索与信息提炼能力）
会议邀约： “帮我写个下周一开项目启动会的通知，别太死板。”（测试文案风格适配与要素补全）
PPT 大纲： “要做一个关于‘数字化转型’的汇报 PPT，给个思路。”（测试从宏观概念到执行逻辑的拆解）
面试准备： “下周二我要去面高级产品经理，帮我突击一下。”（测试模拟面试与知识库匹配）
二、 技术与开发场景 (快速上手)
项目初始化： “我想写个简单的待办清单 App，帮我搭个架子。”（测试代码脚手架生成与技术选型建议）
Bug 排查： “网页布局乱了，帮我看下是怎么回事。”（在信息不全的情况下，测试其引导提问或常见错误预判）
代码重构： “这段代码跑是能跑，但感觉写得太烂了，改改。”（测试对代码规范和优雅度的自主优化）
环境配置： “我想在本地跑 DeepSeek 模型，怎么弄最快？”（测试对复杂技术文档的简化输出）
正则编写： “帮我写个验证复杂密码的正则表达式。”（测试特定技术任务的精准执行）
三、 个人生活与规划 (模糊决策)
旅行规划： “想去西藏玩 7 天，不想太累，帮我排下。”（测试基于限制条件的自主规划）
副业探索： “我是个文案，想赚点外快，有什么靠谱路子？”（测试基于用户画像的方案推荐）
送礼建议： “给程序员男朋友准备生日惊喜，预算 500。”（测试创意生成与逻辑关联）
健身计划： “每天只有半小时，怎么在家高效练出腹肌？”（测试场景化方案的定制能力）
健康科普： “最近老是熬夜心慌，我该注意点啥？”（测试专业知识的科普化表达与风险警示）
四、 学习与知识消费 (复杂简化)
论文精读： “这篇长论文的核心贡献到底是什么？说人话。”（测试长文本摘要与通俗化翻译）
冷门概念： “量子纠缠是怎么回事？用小学生的例子讲一下。”（测试跨领域解释与类比能力）
语言学习： “我想练口语，帮我模拟一个餐厅点餐的场景。”（测试交互式情境创建）
纠错提升： “帮我润色一下这段英文邮件，要显得专业且礼貌。”（测试语境理解与微调执行）
法律/政策解读： “刚出的这个个税政策，对我这种月入两万的有什么影响？”（测试对枯燥条文的自主计算与分析）
五、 上下文压缩与信息密度测试（长文本处理能力）
极简摘要： 先输入一段 2000 字的杂乱会议纪要，然后问：“用 3 句话告诉我，谁要为进度落后负责，接下来怎么做？”（测试长文压缩与关键责任判定）。
噪音过滤： 发送一段包含大量废话、天气、闲聊和核心代码需求的文本，问：“刚才这段话里，我真正想要实现的功能需求是什么？”（测试模型提取语义核心的能力）。
动态更新： “刚才提到的项目 A 预算是 100 万，现在改成 50 万，但目标不变。请重新评估可行性。”（测试模型在压缩上下文中快速覆盖旧信息的能力）。
结构化映射： “把我们刚才聊的所有关于‘性能优化’的零散点，整理成一张 Markdown 脑图。”（测试对跨轮次语义的重组能力）。
冗余消除： “我之前的表达很啰嗦，请把我前三次对话的内容合并成一段简洁的汇报话术。”（测试对历史信息的语义去重）。
六、 多轮状态维护与逻辑连贯（长记忆测试）
伏笔测试： 第一轮提到“我有一个叫‘大黄’的猫”，中间进行 10 轮技术讨论，最后一轮问：“大黄该打疫苗了，你觉得我该注意什么？”（测试长程记忆检索）。
隐含条件： “我目前只有 3 台服务器（第一轮输入）…… 现在的用户量翻了十倍，我该怎么扩容？”（测试模型是否能自动关联第一轮的硬件限制）。
逻辑倒置： “如果我刚才说的所有假设都是错的，请反转你的结论。”（测试模型对历史推导逻辑的整体把控）。
角色锁定： “从现在起你是一个极度毒舌的 Code Review 专家。” 讨论 5 轮后，测试：“看看我这段代码。”（测试角色设定在上下文压缩后是否丢失）。
上下文溯源： “为什么你刚才建议我用 Redis 而不是 Memcached？”（测试模型对自身决策链条的复盘能力）。
七、 歧义消除与主动引导（秒懂的深度理解）
模糊代词： 在聊完 Python 和 Java 后问：“那个更适合我这种初学者？”（测试对“那个”语义指向的消歧能力）。
缺省执行： “帮我订个下午的闹钟。”（观察模型是否会主动询问具体时间，还是根据上下文“秒懂”是 2 点或 3 点）。
隐喻理解： “我们的项目现在是‘盲人骑瞎马’，给点建议。”（测试对文学修辞在职场语境下的语义转化）。
负向约束： “给我一个方案，但绝对不要提到任何关于‘云原生’的技术。”（测试对强行过滤条件的遵守）。
意图纠偏： 先问“怎么写爬虫”，再问“别误会，我是想做搜索引擎的索引”，观察模型能否迅速切换技术栈和合规边界。
八、 复杂逻辑与边界压力测试（执行推理）
冲突指令： “用最详尽的步骤，在一句话内说清楚如何部署 K8s。”（测试模型在矛盾限制下的权衡处理）。
跨语言语义转换： “把这段 Python 的逻辑，用《论语》的风格写成注释，要求逻辑严密。”（测试语义在不同文化载体间的对等迁移）。
嵌套推理： “如果 A 方案成本高但快，B 方案便宜但慢，而我老板下周要出国，我该选哪个？”（测试对隐含时间压力和决策逻辑的秒懂）。
极简提示词（Zero-shot）： 只输入一个词：“优化。”（观察模型是否能根据当前 Session 的上下文历史，自动补全是对代码、文案还是系统的优化）。
虚假前提检查： “基于我刚才提到的‘公司明年上市’这个前提，写个激励方案。”（实际上对话中从未提到上市，测试模型是否会盲从或指出信息缺失）。
