Lite(quick)模式产品功能规格说明书
1. 概述
Lite(quick)模式旨在为用户提供快速、直观、且具备深度推理能力的对话体验。它专注于“问答-执行-呈现”的极致闭环，通过折叠复杂的推理逻辑（CoT），保持界面的简洁，同时利用 Agno 的工具链保证回答的准确性。

2. 多模态交互输入
2.1 长文本编辑
特性：输入框支持无限长文本，具备自动高度调节（Auto-resize）功能。
交互：最高可扩展至屏幕高度的 40%，超出后转为内部滚动。
2.2 多附件管理
上传方式：
点击上传
拖拽上传（Drag & Drop）
支持格式：
文档类：PDF, Docx, TXT, MD
图片类：PNG, JPG, JPEG
实时预览：附件上传后在输入框上方显示缩略图或文件图标，支持点击删除。
3. 预处理引擎 (Agno FileContext)
文档解析：使用 Agno 的 FileContext 自动提取文本内容，保持段落结构。
OCR 识别：集成视觉模型（专用 OCR 插件），对上传的 PNG/JPG 图片进行文字提取，并将其作为文本上下文。
元数据提取：自动识别文件名称、大小、页数，方便模型在引用时提及。
4. 上下文与知识库 (Context & RAG)
4.1 会话记忆管理
N 轮历史回溯：系统自动维护会话窗口，默认携带最近 N 轮（可配置，如 10 轮）的历史对话，确保连贯性。
上下文压缩：当历史记录过长时，利用 Agno 的摘要功能进行上下文压缩，节省 Token。
长记忆：支持使用“长记忆”功能，将历史记录保存到本地/云端的Graph数据库，后续会话可直接加载。
4.2 动态知识库挂载
临时 RAG：将当前会话上传的附件实时向量化，挂载为知识库的文件（Temporary Knowledge Base）。
检索增强：模型在回答时优先检索已挂载的附件内容，确保回答基于用户提供的材料。
5. 模型推理与工具链 (Reasoning & Tools)
5.1 逻辑推理 (Agno CoT)
思维链渲染：调用 Agno 自带的 Chain of Thought (CoT) 功能。
UI 展示：在内容输出前，展示 Thought process 模块。
默认状态：精简显示当前思考步骤（如：“正在搜索...”）。
交互逻辑：用户点击可展开完整的逻辑推理路径。
5.2 增强工具集 (Agno Tools)
系统根据用户意图自动识别并调用以下 Agno 插件：
网络搜索：调用 DuckDuckGo 或 Google Search 实时获取时事。
计算引擎：调用 Python Interpreter 进行精确的数学计算。
语言处理：针对特定语言请求触发翻译或语法润色工具。
知识库查询：支持用户直接查询知识库中的内容，无需通过模型推理。
图谱检索：支持用户混合检索知识库和图谱中的内容，无需通过模型推理。
Skills：支持用户调用外部技能（如函数调用），扩展模型能力。
MCP：支持用户调用自研或外部三方的MCP服务。
6. 输出产物与格式化 (Output & Formatting)
6.1 内容生成 (Content Generation)
生成逻辑：基于推理结果（Thought）和工具返回数据（Tool Data），生成语气自然、结构严谨的最终文本。
流式输出：采用 Server-Sent Events (SSE) 技术，实现字符级的实时流式响应。
6.2 格式化标准 (Format Standards)
利用 Agno 的格式化功能，确保输出内容包含以下标准组件：
Markdown 支持：标题、加粗、斜体、引用块等基础语法。
结构化组件：
文档引用 (Citations)：引用附件或知识库内容时，在文内标注 [1]，鼠标悬停显示来源。
多媒体：渲染图片、点击可查看大图。
交互式表格：支持行列清晰的 Markdown 表格。
代码沙箱：带有语法高亮、语言标签及“一键复制”的代码块。
数学公式：集成 LaTeX 渲染引擎（如 KaTeX），显示复杂的数学公式。
图表插件：支持 Mermaid.js 语法，自动渲染流程图、时序图、饼图。
链接卡片：自动将 URL 转换为带有标题和图标的预览卡片。
文件卡片：展示已上传的附件，支持点击预览、下载。
知识库卡片：展示知识库中的内容，支持点击跳转。
图谱卡片：展示图谱中的内容，支持点击跳转。
代码卡片：展示代码块，支持点击复制。
表格卡片：展示表格数据，支持点击复制。
7. 交互 UI 规范 (UI/UX)
模块化布局：
顶部：Thought process（可折叠式思考记录）。
中部：Used tool（胶囊样式显示已调用的工具标签）。
主体：Rich Text Content（渲染后的 Markdown 内容）。
底部：参考文献列表（References）及操作按钮（复制、重新生成）。
